01 · Antes de tocar nada

¿Qué es Twenty?

Twenty es un CRM de código abierto presentado como alternativa moderna a Salesforce. Sirve para centralizar contactos, empresas, operaciones comerciales, tareas, notas, correos, reuniones, paneles y automatizaciones.

Personas

¿A quién conoces?

Nombre, cargo, teléfono, correo, empresa e historial de interacciones.

Negocio

¿Qué puedes vender?

Oportunidades, importe, fase, fecha prevista de cierre y responsable.

Acción

¿Qué toca hacer?

Tareas, notas, reuniones y automatizaciones para que nada se quede parado.

Importante. “Open source” no significa que alojarlo sea gratis: un servidor, las copias, el correo y el mantenimiento también cuestan. La diferencia es que puedes controlar el sistema y tus datos.

03 · La idea fundamental

El modelo de datos

Twenty organiza la información en objetos. Los cinco objetos estándar que necesitas conocer son:

People · Personas

Contactos individuales. El correo es único: dos personas no pueden compartir la misma dirección.

Companies · Empresas

Organizaciones y clientes. Se relacionan con personas y oportunidades; el dominio identifica a la empresa.

Opportunities · Oportunidades

Ventas o proyectos potenciales con etapa, valor, empresa asociada y fecha de cierre.

Tasks · Tareas

Acciones pendientes, responsable, vencimiento y estado, ligadas a cualquier registro.

Notes · Notas

Actas, contexto, decisiones y detalles que deben quedar asociados al cliente o proyecto.

Objetos propios

Puedes crear “Proyectos”, “Inmuebles”, “Licitaciones” o cualquier entidad con vida propia.

05 · Migrar datos

Importar desde Excel o CSV

No vuelques todo de golpe. Limpia primero duplicados, correos incorrectos y nombres inconsistentes.

Orden obligatorio recomendado:
  1. Companies primero.
  2. People después, relacionándolas mediante el dominio de la empresa.
  3. Opportunities al final.
  1. Guarda cada tabla como CSV UTF-8.
  2. Deja una fila de cabeceras clara: name, email, phone, companyDomain…
  3. En Twenty abre el menú de comandos con Ctrl+K o Cmd+K.
  4. Selecciona Import e indica el objeto de destino.
  5. Mapea cada columna con su campo de Twenty.
  6. Revisa una muestra antes de confirmar.
Evita duplicados. Twenty usa el correo como identificador único de People y el dominio para Companies. La documentación recomienda archivos de hasta 10.000 registros por importación.
06 · Memoria comercial

Conectar correo y calendario

  1. Ve a Settings → Accounts → Add account.
  2. Elige Google, Microsoft o configura SMTP/CalDAV para otros proveedores.
  3. Decide la visibilidad: metadatos, asunto o contenido completo.
  4. Selecciona las carpetas que quieres sincronizar.
  5. Activa, si te conviene, la creación automática de contactos.
Sí sincroniza

Relaciones externas

Correos y reuniones con contactos externos se vinculan a Personas, Empresas y Oportunidades.

No sincroniza

Privacidad interna

Los correos entre compañeros del mismo dominio y las listas de distribución se excluyen.

Limitación actual: el manual de usuario indica que la interfaz sirve para leer el historial; para contestar, Twenty abre el hilo en Gmail u Outlook. Los workflows sí pueden enviar correos automáticos mediante una cuenta conectada.

09 · Para quien quiere control

Autoalojar con Docker

Necesitas Docker y Docker Compose actualizados, al menos 2 GB de RAM y conocimientos básicos de servidor. Para producción utiliza dominio, proxy inverso y HTTPS.

Instalación rápida oficial

bash <(curl -sL https://raw.githubusercontent.com/twentyhq/twenty/main/packages/twenty-docker/scripts/install.sh)

Cuando termine, abre http://localhost:3000 si lo has instalado en tu ordenador.

Instalación manual resumida

  1. Descarga el archivo .env.example y renómbralo como .env.
  2. Genera una clave con openssl rand -base64 32 y guárdala como ENCRYPTION_KEY.
  3. Define una contraseña robusta para PostgreSQL.
  4. Descarga el docker-compose.yml oficial.
  5. Arranca con docker compose up -d.
  6. Para acceso externo configura SERVER_URL y HTTPS.
No pierdas la ENCRYPTION_KEY. Sin ella no podrás acceder a secretos cifrados guardados en la base de datos, como tokens OAuth, variables privadas o claves TOTP.
10 · Lo que evita disgustos

Copias y actualizaciones

Copia de la base de datos

docker exec twenty-postgres pg_dump -U postgres twenty > backup_$(date +%Y%m%d).sql

Antes de actualizar

  1. Haz una copia y comprueba que puede restaurarse.
  2. Guarda también el archivo .env y la clave de cifrado en un gestor seguro.
  3. Revisa las notas de la versión que vas a instalar.
  4. Detén Twenty, cambia la etiqueta de versión y vuelve a arrancar.

Copias 3-2-1

Tres copias, en dos soportes distintos y una fuera del servidor. Cifra los ficheros y conserva diarios, semanales y mensuales.

RGPD

Define base jurídica, minimización, plazos de conservación, usuarios autorizados y procedimiento de ejercicio de derechos. Autoalojar no resuelve por sí solo el cumplimiento.

12 · Errores frecuentes

No hagas esto

Importarlo todo

Un CRM lleno de datos viejos y duplicados se abandona enseguida.

Crear 30 campos

Empieza con lo imprescindible. Añade un campo cuando exista una decisión que dependa de él.

Automatizar el caos

Primero valida el proceso manual; luego automatiza sus pasos repetitivos.

Olvidar el responsable

Cada oportunidad y tarea debe tener una persona dueña del siguiente paso.

No hacer copias

Un volumen Docker no sustituye una copia externa probada.

Compartir secretos

No publiques el archivo .env, la ENCRYPTION_KEY, contraseñas ni claves API.
